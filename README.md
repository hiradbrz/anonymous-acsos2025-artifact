# PipeMind 2.0 (ACSOS 2025 Artifact)

This repository contains the anonymized code, synthetic pipelines, configuration files, and demonstration materials for the PipeMind 2.0 framework submitted to ACSOS 2025.

## Contents

- `pipelines/`: Sample BPMN workflows across multiple domains.
- `modules/`: Python task modules linked to pipeline nodes.
- `pac_configs/`: Agent and task definitions for CrewAI orchestration.
- `demo/`: Screencast of GUI and optimization process.
- `evaluation/`: Benchmark results and performance logs.
